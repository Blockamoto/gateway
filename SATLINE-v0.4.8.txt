SATLINE v0.4.8
PERSISTENT ON-DEMAND ORDINAL LINEAGE

Satline remains on-demand: no global sat index is built.

A queried lineage stores:
- sat number or starting satpoint
- issuance/birth context where applicable
- verified hop references
- block-hash anchors
- current satpoint
- terminal state/snapshot

On a later query, Satline validates the stored chain anchors and resumes from the latest valid checkpoint. If a reorg invalidates recent history, only the stale suffix is discarded.

Satline is a bundled Gateway module that depends on Bitcoin on Demand for Bitcoin evidence and graph traversal. It is not advertised as a remote Gateway protocol in v0.4.8.
