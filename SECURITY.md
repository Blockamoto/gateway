# Security reporting

Please report suspected credential exposure, unauthorized local API access, unsafe update acceptance, arbitrary file writes or comparable vulnerabilities privately before posting details publicly.

If GitHub offers **Report a vulnerability** on this repository's Security page, use that private channel. Otherwise open a minimal [issue](https://github.com/Blockamoto/gateway/issues) asking for a private reporting contact, without exploit details or sensitive data. No public email address is designated here.

Include the affected version/platform, impact, a minimal reproduction and relevant redacted logs. Never send private keys, passwords, tokens, wallet files or an entire Gateway profile. Request coordination before sharing a sensitive sample with a third party.

Security fixes target the current release. This testing software has no promised response time or long-term support schedule. The [privacy guide](docs/PRIVACY.md) and [known issues](docs/KNOWN-ISSUES.md) describe intended behavior and current limitations; they do not establish that a reported vulnerability is harmless.
