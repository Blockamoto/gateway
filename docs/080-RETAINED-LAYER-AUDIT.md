# Enabled and retained layer audit

The required writer scope is the enabled 0.7.9 catalogue, including independent
optional retained layers. Availability, saved historical data and a physical
source cache are different contracts. `release_availability.go`,
`bitmap_capabilities.go` and `index_catalog.go` preserve that distinction.

| Layer | Executable policy / preserved responsibility |
| --- | --- |
| Selected headers; located and hash-only Raw bodies | Actual header/block/body JSON; existing chain selection, consensus-context checks, retention consent, journals and segment/catalogue codecs. |
| TX IDs; Lean/Full positional inscriptions; conventional-ID enrichment | Actual independent JSON documents; native compact/reverse codecs and separately retained coverage. |
| Values; exact scripts; both fields | Three actual output-fact JSON policies shared by Raw/TXIO native writers; independently editable saved projections. |
| TXIO resolved links and pending translations | Actual full JSON, with four explicit positive creation-evidence ports; no miss implies unspentness. |
| Coin; current addresses; address history | Actual ordered/checkpoint/sparse JSON; source-owned facts, state and recovery remain explicit. |
| Sat FIFO current state and optional original ranges | Actual current/history JSON; physical range pages, identity codecs, savepoints and required shared facts remain with the declared state owner. |
| Compact fee pages and block manifests | Actual input/output fee derivation and checked Core prefix JSON; unchanged native pages/manifests and reader. |
| Standard District and validated replay Parcel candidates/winners | Actual policy JSON; exact District input, checked provenance primitive, independent route admission and native physical codecs. |
| Replay receipts, movement blocks, negative attestations and locator audits | Source/proof evidence, not separate index policy. Generic checked inscription-parent replay supplies the declared point port. Used proof bytes are independently copied into saved child source blobs; a local negative attestation retains its local trust boundary. Existing route audit/receipt formats and selected-chain checks remain. |
| Old Raw record/segment migration | Historical physical conversion/readers remain. Migration is not automatic custom indexing and cannot grant new coverage from a renamed recipe. |
| Canonical inscription numbering | Historical readers/repair code retained; catalogue identity remains locked and not buildable. Lean/Full positional processing never starts it. It was not an enabled 0.7.9 writer to convert or activate. |
| Previous Bitmap generations, development Chains and custom comparison profiles | Saved records, definitions and evidence remain readable under their original identities. New execution stays gated; JSON conversion does not relabel them Standard. |
| Satline forward/reverse trace, resume and reverse-result caches | Existing saved data/readers retained; public tracing stays deferred. Core fee facts are a separate explicitly selected source, not permission to start tracing. |
| Work journals, source acquisition caches, append markers, coverage/catalogue pages and notification epochs | Host storage, acquisition and publication mechanisms. They neither select recipe policy nor serve as disguised whole-index operators. Notifications carry no proof. |

Every enabled native index and independent optional retained derivation has an
actual editable JSON document. Gated historical writers remain preserved rather
than being silently enabled. Native identities/formats are protected by reviewed
semantic bindings and frozen writer comparisons. New custom generations retain
their own semantic identity and never inherit native coverage by name.

This inventory closes the mapping question, not complete release acceptance.
Family evidence is in `080-PARITY-MATRIX.md`; the isolated working preview and
visible Chrome audit still need to be recorded. Full-chain performance and a
positive mainnet Bitmap Parcel remain outside the bounded fixtures.
