# Gateway 0.7.9 release and delivery status

As of 2026-10-30, [0.7.9 Parcels](https://github.com/Blockamoto/gateway/releases/tag/v0.7.9) is a published prerelease. Tag `v0.7.9` resolves to `a9b1722aee6d150af96822da2329ae54bf178de0`, the source recorded in the packages. All nine initially published assets were independently downloaded and matched the audited package bytes. The final source [development checks](https://github.com/Blockamoto/gateway/actions/runs/40975980897) passed, as did [published Linux package acceptance](https://github.com/Blockamoto/gateway/actions/runs/40978012589).

The signed canonical `gateway-update-feed-v0.7.9.zip` was uploaded and independently authenticated against the pinned public key. It records application sequence 18, header sequence 17, and the same validated 969,480-header snapshot as 0.7.8. Its SHA-256 is `35a1db9ca3e478e8dca8aabc8d60190ad1f5b3e6c88507ce193bd37516180a1b`. Authenticated download matched it byte for byte; anonymous full downloads from the release operator's environment repeatedly ended early, though the returned prefix and a separate tail range matched. Public hosted-feed delivery has not been verified.

The existing Render `gateway-updates` service remains on the verified 0.7.8 application feed at sequence 17. Render canceled automatic and environment-only deployments because the workspace exhausted its build pipeline minutes. The service setting and committed renewal target were restored to 0.7.8; no billing settings were changed. The live 0.7.8 application manifest expires on 2026-11-26 at 11:58:16 UTC. Renewals and the live predecessor must be rechecked before retrying 0.7.9 activation; if 0.7.8 has advanced, prepare a fresh higher-sequence 0.7.9 feed as needed. A genuine hosted 0.7.8-to-0.7.9 client upgrade, hosted 0.7.9 manifest/download checks, and post-promotion renewal remain pending.

The Windows candidate passed isolated two-block Sat pause/resume/restart, Address History and TX-locator fanout, navigation, and Parcel start-choice checks. The installer payload and preview were checked; a real Windows installation was not performed because it writes shared account registration and shortcuts. Full-mainnet Parcel replay, Live throughput, storage requirements and a positive replay-v3 Bitmap target-coverage fixture remain unverified. These limitations are not replaced by the release or updater checks.
