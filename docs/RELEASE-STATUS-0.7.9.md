# Gateway 0.7.9 release and delivery status

As of 2026-11-01, [0.7.9 Parcels](https://github.com/Blockamoto/gateway/releases/tag/v0.7.9) is a published prerelease and is available through the existing Render updater. Tag `v0.7.9` still resolves to `a9b1722aee6d150af96822da2329ae54bf178de0`, the source recorded in the packages. All nine initially published assets were independently downloaded and matched the audited package bytes. The final source [development checks](https://github.com/Blockamoto/gateway/actions/runs/40975980897) passed, as did [published Linux package acceptance](https://github.com/Blockamoto/gateway/actions/runs/40978012589).

The initial signed `gateway-update-feed-v0.7.9.zip` records application sequence 18, header sequence 17, and the same validated 969,480-header snapshot as 0.7.8. Its SHA-256 is `35a1db9ca3e478e8dca8aabc8d60190ad1f5b3e6c88507ce193bd37516180a1b`. Both predecessor and candidate were freshly restored with the pinned public key before activation: the live predecessor matched the authenticated 0.7.8 bundle at application/header sequences 17/16, and both candidate sequences advanced. Render fetched and authenticated the public candidate successfully. The hosted application and header envelopes matched the signed bundle byte for byte; both Windows and Linux update archives and all 97 header chunks downloaded through Render and matched their signed lengths and hashes.

The October build-minute exhaustion prevented initial delivery. On 1 November a capacity-check deployment completed successfully, followed by the 0.7.9 activation deployment `dep-dbjhte8ae00c73e9etfg`, which became live at 11:13:53 UTC. The service setting and committed renewal target now select 0.7.9. No billing settings, trust key, updater endpoint or released executable bytes changed.

All four executable hashes matched the audited release. Settings, theme, index sentinel, bootstrap files, complete existing header file and management origin were preserved. A separate fresh 0.7.9 client checked both hosted feeds automatically without manual publisher setup; its validated snapshot remained intact and ordinary peers extended it to 974,120 headers. Browser errors and unexpected browser requests were absent, and disposable runtimes and profiles were removed. See the [operational delivery acceptance record](RELEASE-DELIVERY-ACCEPTANCE-0.7.9.json). The packaged candidate-stage record remains unchanged.

Existing clients discover the update on their next check and follow their saved notification or automatic-install preference.

The Windows candidate passed isolated two-block Sat pause/resume/restart, Address History and TX-locator fanout, navigation, and Parcel start-choice checks. These limitations are not replaced by the release or updater checks.
